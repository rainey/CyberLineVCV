# cyberline

Physical-modelling voice synthesis for VCV Rack / Cardinal, built from
patchable atoms: a LF-glottis **Larynx**, a Kelly–Lochbaum **Oral Chamber**
with nasal branch and variable tract length (species-ready), and a fused
**Voice** module. MIT licensed.

- Spec: `docs/spec.md` (v0.1 draft — the authoritative plan)
- Status: pre-implementation; no module code yet
- Reference collection (external, not part of this repo):
  `../refs/` — papers, MIT implementations, theory notes
